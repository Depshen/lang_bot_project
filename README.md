## Описание проекта

Программа представляет собой интерактивного Telegram-бота, разработанного на языке Python с использованием асинхронной библиотеки `python-telegram-bot`, который помогает пользователям изучать польский язык. Бот позволяет в удобном формате мессенджера получать ежедневные слова с переводом, проходить тематические мини-уроки с транскрипцией и отслеживать персональную статистику обучения. Все взаимодействия обрабатываются в режиме реального времени через систему команд Telegram API.

## Функциональные возможности

### Основной функционал

* **Регистрация и приветствие (`/start`):** автоматическая инициализация профиля пользователя в базе данных прогресса и вывод главного меню с доступными командами.
* **Слово дня (`/word`):** случайная выборка польского слова из словаря бота с переводом на русский язык для расширения словарного запаса.
* **Мини-уроки (`/lesson`):** отправка структурированных учебных карточек с правилами этикета, произношением (транскрипцией) и примерами использования фраз.
* **Отслеживание прогресса (`/progress`):** подсчет и отображение индивидуальной статистики пользователя (количество выученных слов и пройденных мини-уроков за сессию).
* **Справочная система (`/help`):** быстрый вызов подсказки по работе с ботом.

### Дополнительный функционал

* **Автоматическое логирование:** запись всех событий запуска, сетевых запросов и возможных ошибок в консоль с помощью встроенного модуля `logging`.
* **Изоляция конфигурации:** хранение секретного токена авторизации Telegram API в отдельном модуле `config.py`.
* **Асинхронная обработка:** неблокирующая работа с серверами Telegram по технологии Long Polling (`run_polling`), позволяющая боту отвечать нескольким пользователям одновременно.

## Требования к системе

* **Python:** версия 3.9 или выше (проект протестирован на Python 3.12)
* **Операционная система:** macOS / Windows / Linux
* **Доступ в интернет:** требуется активное соединение для связи с серверами `api.telegram.org`
* **Библиотеки:**
  * `python-telegram-bot` (версия 20.x / 21.x) — основная библиотека для взаимодействия с Telegram Bot API
  * `logging` — стандартный встроенный модуль Python для журналирования работы программы
  * `random` — стандартный встроенный модуль Python для генерации случайных слов

## Установка и запуск

Ниже приведена подробная пошаговая инструкция, позволяющая развернуть и запустить бота на любом компьютере.

### 1. Клонирование репозитория

Откройте терминал (на macOS/Linux) или командную строку / PowerShell (на Windows), перейдите в рабочую директорию и выполните команды:

```bash
git clone https://github.com/Depshen/lang_bot_project.git
cd lang_bot_project
```

### 2. Создание и активация виртуального окружения

Проект использует изолированное виртуальное окружение `venv`.

**Для macOS и Linux:**

```bash
python3 -m venv venv
source venv/bin/activate
```

**Для Windows:**

```bash
python -m venv venv
venv\Scripts\activate
```

*(После успешной активации в начале командной строки терминала появится префикс `(venv)`).*

### 3. Установка зависимостей

Установите библиотеку `python-telegram-bot` и все необходимые сетевые зависимости из файла `requirements.txt`:

```bash
pip install -r requirements.txt
```

### 4. Настройка токена бота

Для работы программы необходим токен аутентификации от официального бота **@BotFather** в Telegram:

1. Откройте Telegram, найдите `@BotFather` и отправьте команду `/newbot`.
2. Укажите имя и `username` бота (должен заканчиваться на `bot`), после чего скопируйте полученный API-токен.
3. Откройте файл `config.py` в корне проекта и вставьте ваш токен в кавычках:

```python
BOT_TOKEN = "ВАШ_ТОКЕН_ОТ_BOTFATHER"
```

### 5. Запуск программы

Находясь в папке проекта с активированным виртуальным окружением, запустите главный скрипт:

**На macOS / Linux:**

```bash
python3 main.py
```

**На Windows:**

```bash
python main.py
```

После успешного запуска в терминале появится сообщение:
`INFO - Application started` — это означает, что бот вышел в сеть и готов принимать сообщения.

### 6. Управление ботом

**В мессенджере Telegram:**
Найдите вашего бота по `username` и используйте команды (вручную или кликая по синим ссылкам в сообщении бота):
* `/start` — запуск бота и просмотр меню
* `/word` — получить новое польское слово (+1 к статистике слов)
* `/lesson` — пройти мини-урок по польскому языку (+1 к статистике уроков)
* `/progress` — проверить текущее количество изученных материалов
* `/help` — открыть справку

**В терминале (на компьютере):**
* `Ctrl + C` — безопасная остановка работы бота и завершение процесса в терминале.

## Структура проекта

```text
lang_bot_project/
├── .gitignore          # Исключения системы контроля версий (__pycache__, *.pyc, .DS_Store)
├── README.md           # Визитная карточка проекта, описание и инструкция по запуску
├── requirements.txt    # Список внешних зависимостей (python-telegram-bot, httpx и др.)
├── config.py           # Модуль конфигурации для хранения BOT_TOKEN
├── main.py             # Точка входа, инициализация приложения и обработчики команд
└── venv/               # Виртуальное окружение Python (включено в репозиторий для проверки)
```

**Назначение основных модулей и обоснование структуры:**

* `config.py` — выносит конфигурационные данные (токен доступа к API) за пределы основной логики программы.
* `main.py` — содержит словарь лексики `VOCABULARY`, хранилище сессий `user_progress`, асинхронные функции-обработчики (`start`, `send_word`, `send_lesson`, `check_progress`, `help_command`) и функцию запуска `main()`.
* **Обоснование структуры:** архитектура с разделением на конфигурационный файл (`config.py`) и основной модуль обработчиков (`main.py`) полностью соответствует методическим указаниям к практической работе № 2. Такая структура позволяет отделить чувствительные настройки от бизнес-логики, сохраняя при этом прозрачность кода, полное соответствие стандартам PEP 8 и наличие документации PEP 257 для каждой функции.
